## [1.0.0] - 2026-08-05

### Added

- Java 21 and Spring Boot modular-monolith API with JWT access tokens, rotated
  opaque refresh sessions, role checks, ownership boundaries, and RFC 7807
  errors.
- PostgreSQL/Flyway persistence with immutable ledger entries, deterministic
  wallet locking, and atomic, persistently idempotent transfers.
- React and TypeScript interface for wallets, transactions, transfers, budgets,
  notifications, analytics, profile management, and administration.
- Deterministic synthetic demo data plus API, component, integration,
  concurrency, and Playwright end-to-end tests.
- Non-root multi-stage Docker image, Docker Compose environment, Codespaces,
  Render/Neon configuration, GHCR publishing, SBOM/provenance, and attestations.
- GitHub Actions CI, CodeQL scanning, verified portfolio screenshots, GitHub
  Pages showcase, architecture records, security documentation, and API guides.
