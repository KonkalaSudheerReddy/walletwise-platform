Understand your virtual money. Move it safely.

WalletWise is a secure digital wallet and expense-management platform built to demonstrate practical backend engineering: immutable ledger entries, atomic balance changes, persistent idempotency, ownership checks, and useful financial analytics.

Product capabilities

A focused financial-tracking workflow

01

Wallets and ledger

Create virtual wallets, record income and expenses, archive wallets, and inspect immutable transaction history.

02

Safe transfers

Move virtual funds atomically while deterministic row locking and idempotency keys protect against duplicate updates.

03

Budgets and alerts

Set monthly category limits, monitor utilization, and receive deduplicated approaching, reached, or exceeded alerts.

04

Search and analytics

Filter paginated ledger activity and review monthly income, spending, category breakdowns, and wallet balances.

05

Secure sessions

Use short-lived JWT access tokens with rotated, hashed opaque refresh tokens delivered in an HttpOnly cookie.

06

Operational visibility

Trace requests with correlation IDs, safe audit records, structured logs, and narrowly exposed Actuator health information.

Deployment topology

One application, clear module boundaries

React assets and the versioned REST API are served from one Spring Boot process in production. PostgreSQL remains the durable source of truth for wallets, ledger entries, tokens, idempotency records, budgets, notifications, and audits.

  1. React + TypeScript Accessible responsive interface
  2. Spring Boot API Authentication, validation, and business modules
  3. PostgreSQL 16 Flyway-managed relational state

Engineering spotlight

A transfer is one database transaction

WalletWise locks both owned wallets in stable UUID order, validates currency and available balance, then writes the transfer, two linked ledger entries, both new balances, and an audit event. Any failure rolls back the complete operation.

  1. 1 Reserve the caller-scoped idempotency key.
  2. 2 Lock wallet rows in deterministic order.
  3. 3 Validate ownership, currency, and funds.
  4. 4 Commit both sides of the ledger atomically.
  5. 5 Replay the stored response on a safe retry.

Try the project

One command to start locally

Clone the repository, make sure Docker is running, and start the application and PostgreSQL together. The UI is served at http://localhost:8080. 

git clone https://github.com/KonkalaSudheerReddy/walletwise-platform.git
cd walletwise-platform
docker compose up --build
